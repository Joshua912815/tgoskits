# Phase 4: TTY Readline Record

This is a short factual record for later expansion.

## Goal

Phase 4 fixes the StarryOS tty/readline path so `picoclaw agent` can run in
interactive mode inside StarryOS x86_64 QEMU.

The acceptance target is:

```bash
picoclaw agent
```

After entering interactive mode, users should be able to type multiple messages
directly and use `exit` to return to the shell.

## Result

Phase 4 interactive PicoClaw input passed on StarryOS x86_64 QEMU.

The observed failure before this phase was:

```text
picoclaw agent
Interactive mode (Ctrl+C to exit)
```

At that point keyboard input appeared to have no effect. A pipeline workaround
like `cat | picoclaw agent` could still deliver messages, which showed that the
agent loop and network path were basically usable. The broken part was the
terminal/readline layer.

After the fix, bare `picoclaw agent` accepts direct keyboard input in the QEMU
serial console, supports multi-turn messages, and returns to the shell after
`exit`.

## Problems Found

1. PicoClaw's readline layer writes the ANSI cursor position query `ESC [ 6 n`.

   StarryOS printed the bytes to the console but did not provide a cursor
   position response. Readline-style code then waited for terminal state that
   never arrived, so user input looked stuck.

2. The tty line discipline had no small internal path for synthetic terminal
   response bytes.

   The fix adds an injected-input queue so terminal responses generated by the
   kernel tty device can be delivered through the same read path as normal input.

## Files Changed

- `os/StarryOS/kernel/src/pseudofs/dev/tty/mod.rs`
  - Detects ANSI cursor position query bytes written to a foreground tty.
  - Injects a minimal cursor position response: `ESC [ 1 ; 1 R`.
  - Adds a byte-search helper used by the tty write path.

- `os/StarryOS/kernel/src/pseudofs/dev/tty/terminal/ldisc.rs`
  - Adds an internal injected-input queue.
  - Makes injected input immediately readable and visible to poll.
  - Clears injected input on tty input drain.
  - Adds a unit test for injected input readability.

- `os/StarryOS/kernel/src/syscall/sys.rs`
  - Applies a small clippy cleanup by replacing raw pointer casts with
    `cast::<u8>()`.

- `test-suit/starryos/normal/qemu-smp1/bugfix/bug-tty-cursor-report/c/CMakeLists.txt`
  - Adds the regression test build file.

- `test-suit/starryos/normal/qemu-smp1/bugfix/bug-tty-cursor-report/c/src/main.c`
  - Adds a C regression that writes `ESC [ 6 n` and expects to read
    `ESC [ 1 ; 1 R`.

- `test-suit/starryos/normal/qemu-smp1/bugfix/qemu-aarch64.toml`
- `test-suit/starryos/normal/qemu-smp1/bugfix/qemu-loongarch64.toml`
- `test-suit/starryos/normal/qemu-smp1/bugfix/qemu-riscv64.toml`
- `test-suit/starryos/normal/qemu-smp1/bugfix/qemu-x86_64.toml`
  - Adds `bug-tty-cursor-report` to the bugfix group on all four architectures.

## Verification

- `cargo fmt`
- `cargo xtask clippy --package starry-kernel`
  - 11 checks passed.
- `cargo xtask starry test qemu --arch x86_64 -c bugfix`
  - `bug-tty-cursor-report` passed.
- Manual PicoClaw interactive run:
  - `picoclaw agent` entered interactive mode.
  - Multiple typed messages were accepted directly.
  - `exit` returned to the StarryOS shell.

## Current Boundary

This phase fixes the minimal cursor-position behavior required by PicoClaw's
interactive readline path. It is not a full terminal emulator. Future work can
still validate richer terminal behavior such as arrow keys, Ctrl+C, Ctrl+D,
multi-line editing, long output scrolling, and more complete ANSI responses.
